# DilSe Instagram profile launch set

## Included

- Post 1: one static feed graphic
- Post 2: one static feed graphic
- Post 3: six carousel slides
- Captions and alt text in `PUBLISHING_COPY.md`

All graphics are 1080 × 1350 px.

## Regenerate

Run:

```bash
python3 social/instagram_profile_launch/render_posts.py
```

Upload the Post 3 slides in filename order. Add `www.baatdilse.com` through Instagram's profile link field and pin all three posts after publishing.
